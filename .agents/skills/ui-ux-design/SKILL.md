# UI and UX design

1. Inspect existing screens and identify the user's task, required data, and failure cases before changing layout.
2. Use clear Russian labels and familiar genealogy terms. Keep privacy and sharing choices understandable at the moment they matter.
3. Design for mobile and desktop, keyboard access, readable contrast, and touch-friendly controls.
4. Provide loading, empty, error, permission, success, and conflict states; every visible control must have a real behavior or be clearly disabled with an explanation.
5. Avoid exposing personal data in public page metadata, browser titles, URLs, or notifications.
6. Keep reusable components consistent and avoid mixing domain rules into presentation code.
7. Review the actual rendered result at relevant viewport sizes when UI tooling is available; report visual checks performed.
