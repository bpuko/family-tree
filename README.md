# Семейное древо — сайт и VPS API

Сайт предназначен для закрытого семейного древа. Код интерфейса публикуется через GitHub Pages, семейные записи и аккаунты находятся в PostgreSQL на VPS. В публичном репозитории не хранить сведения о родственниках, пароли, `.env` или резервные копии.

## Состав

- `index.html`, `config.js` — браузерный интерфейс.
- `server/` — API входа, сессий, аккаунтов родственников и общего древа.
- `docker-compose.yml` — PostgreSQL и API; база не публикует порт наружу.
- `Caddyfile` — HTTPS для `api.family-ykt.ru` после направления DNS на VPS.
- `server/backup.sh` — ежедневная резервная копия; timer оставляет локальные копии за 14 дней.

Новая регистрация закрыта. Первый аккаунт владельца создаётся отдельной командой и интерактивно, пароль при вводе не отображается. Только владелец может создать аккаунт редактора. Приглашение создаёт логин и временный пароль; ссылку и данные входа владелец передаёт родственнику сам. Входящих писем приложение не отправляет.

## DNS для выбранной схемы

Корневой адрес `family-ykt.ru` и `www` должны вести на GitHub Pages, а `api.family-ykt.ru` — на IP VPS. Для GitHub Pages использовать актуальные записи из [официальной инструкции](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site). Для API создать `A` запись `api` на IPv4 VPS. Не добавлять неизвестные `AAAA` записи.

## Развёртывание на VPS

ОС на VPS должна получать обновления безопасности. Если система показывает Ubuntu 20.04 без Ubuntu Pro, перед публичным запуском обновить её до поддерживаемой LTS-версии или подключить расширенные обновления. Не переустанавливать ОС без резервной копии существующего диска.

1. Установить поддерживаемые Docker Engine и Compose, создать `/opt/family-tree`, скопировать проект.
2. Создать `.env` из `.env.example`. Сгенерировать отдельные случайные значения `POSTGRES_PASSWORD` и `SESSION_SECRET`; не передавать файл или секреты в GitHub.
3. Выполнить `docker compose up -d --build`, затем убедиться, что `/api/health` отвечает локально.
4. После регистрации домена и DNS включить HTTPS: `docker compose --profile public up -d`. Caddy получает и продлевает сертификат автоматически.
5. Создать владельца командой `docker compose exec app npm run create-owner`. Указать почту владельца; пароль вводить только в скрытый интерактивный запрос.
6. Установить timer резервных копий:

   ```sh
   install -m 0644 deploy/family-tree-backup.service /etc/systemd/system/
   install -m 0644 deploy/family-tree-backup.timer /etc/systemd/system/
   systemctl daemon-reload
   systemctl enable --now family-tree-backup.timer
   ```

Резервные копии в этом варианте лежат на том же VPS, поэтому перед истечением аренды или работами с диском их нужно скачать в отдельное надёжное место. Экспорт проекта из интерфейса также создаёт локальную копию, но не заменяет регулярный бэкап.

## Работа сайта

Публикация интерфейса не делает данные публичными: API требует авторизованную сессию, запросы ограничены разрешёнными адресами сайта, пароли хранятся как хэши scrypt, cookie сессии `HttpOnly` и `Secure`. Все участники имеют роль редактора; роль владельца может создавать аккаунты.

Конфигурация публичной страницы берёт адрес API из `config.js`. Для штатного использования адрес сайта — `https://family-ykt.ru`.
